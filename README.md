1. ВВЕДЕНИЕ
================================================================================

Проект "МЕБЕЛЬ" представляет собой полнофункциональный интернет-магазин мебели,
разработанный на фреймворке Django. Система позволяет управлять каталогом товаров,
категориями, заказами, корзиной покупателя и предоставляет интеграцию с платёжной
системой Stripe.

Основные компоненты:
  • Каталог товаров с многоуровневыми категориями(привязка категорий к своей же модели через поле parent)
  • Система фотографий для товаров
  • Корзина покупателя с управлением товарами
  • Система управления заказами
  • Интеграция с платёжной системой Stripe
  • Система регионов и городов для доставки
  • Администраторский интерфейс


2. ПРОЦЕДУРА УСТАНОВКИ И ЗАПУСКА
================================================================================

2.1 Установка зависимостей
---------------------------
Выполните следующую команду:

  pip install -r requirements.txt

Эта команда установит все необходимые пакеты, перечисленные в файле requirements.txt


2.2 Применение миграций базы данных
------------------------------------
Выполните команду для создания и инициализации базы данных:

  python manage.py migrate

После этого будут созданы все необходимые таблицы в базе данных.


2.3 Загрузка тестовых данных (опционально)
-------------------------------------------
Для загрузки готовых тестовых данных в базу выполните:

  python manage.py loaddata fixtures.json

Примечание: Эта команда заполнит БД категориями, товарами, фотографиями,
регионами и городами для тестирования функционала.


2.4 Создание учётной записи администратора
--------------------------------------------
Создайте учётную запись суперпользователя (администратора):

  python manage.py createsuperuser

Следуйте инструкциям в консоли. Вам потребуется ввести:
  • Имя пользователя
  • Электронную почту
  • Пароль (дважды)


2.5 Запуск тестового сервера
-----------------------------
Для запуска локального веб-сервера выполните:

  python manage.py runserver

По умолчанию сервер будет доступен по адресу: http://127.0.0.1:8000/

4. РАБОТА С ДАННЫМИ И FIXTURES
================================================================================

4.1 Что такое Fixtures?
-----------------------
Fixtures - это файлы в формате JSON, содержащие снимки (копии) данных из базы
данных. Используются для:
  • Создания резервных копий данных
  • Распространения тестовых наборов данных
  • Инициализации среды разработки или тестирования
  • Версионирования данных совместно с кодом


4.2 Операции с Fixtures
------------------------
Загрузка данных из файла в базу:
  python manage.py loaddata fixtures.json

Полная переинициализация базы данных:
  python manage.py flush
  python manage.py loaddata fixtures.json

Примечание: Экспорт данных выполняется с помощью скрипта dump_fixtures.py
по мере необходимости.


5. ОСНОВНЫЕ КОМАНДЫ DJANGO
================================================================================

Создание миграции после изменений в моделях:
  python manage.py makemigrations

Применение всех ожидающих миграций:
  python manage.py migrate

Просмотр статуса применённых и ожидающих миграций:
  python manage.py showmigrations

Создание учётной записи суперпользователя:
  python manage.py createsuperuser

Запуск интерактивной оболочки Python с доступом к моделям:
  python manage.py shell

Запуск тестового веб-сервера разработки:
  python manage.py runserver

Очистка всех данных из базы (осторожно!):
  python manage.py flush


6. АДМИНИСТРАТОРСКИЙ ИНТЕРФЕЙС
================================================================================

Доступ к администраторской панели осуществляется по адресу:
  http://127.0.0.1:8000/admin/

Вход в систему осуществляется с использованием учётных данных суперпользователя,
созданных на этапе установки.

Функционал администратора включает:
  • Управление категориями товаров
  • Добавление, редактирование и удаление товаров
  • Загрузка и управление фотографиями товаров
  • Просмотр и управление заказами
  • Управление учётными записями пользователей
  • Просмотр и ответ на контактные сообщения
  • Управление рейтингами товаров


7. УСТРАНЕНИЕ НЕИСПРАВНОСТЕЙ
================================================================================

7.1 База данных повреждена или требует переинициализации
----------------------------------------------------------
Выполните следующий набор команд:

  del db.sqlite3
  python manage.py migrate
  python manage.py loaddata fixtures.json

Это полностью пересоздаст базу данных и загрузит тестовые данные.


7.2 Миграции не применены
--------------------------
Проверьте текущий статус миграций:
  python manage.py showmigrations

Примените все ожидающие миграции:
  python manage.py migrate

Если проблема сохраняется, проверьте логи ошибок в консоли.


7.3 Ошибки при запуске сервера
-------------------------------
Прежде всего, проверьте лог ошибок в консоли - там должна быть информация
о причине ошибки.

Убедитесь, что выполнены следующие условия:
  • Установлены все зависимости: pip install -r requirements.txt
  • Применены все миграции: python manage.py migrate
  • Порт 8000 не используется другим приложением
  • Нет синтаксических ошибок в коде приложения


7.4 Проблемы с подключением к базе данных
--------------------------------------------
Если при запуске миграций возникают ошибки подключения:
  1. Убедитесь, что файл db.sqlite3 не заблокирован другим процессом
  2. Проверьте права доступа к директории проекта
  3. Попробуйте удалить db.sqlite3 и заново выполнить миграции


8. РАЗВЁРТЫВАНИЕ НА PRODUCTION
================================================================================

При развёртывании на production среду необходимо:
  1. Использовать settings_prod.py вместо settings.py
  2. Установить переменные окружения для конфиденциальных данных
  3. Использовать production веб-сервер (Gunicorn, uWSGI)
  4. Настроить HTTPS и безопасность
  5. Выполнить python manage.py collectstatic

Подробнее см. документацию Django для production развёртывания.
